About the Project

This project is called Into the Grid.
It is a small Python program made to show how Object-Oriented Programming (OOP) works.
It uses classes and objects to build a small world of hackers, rigs, and digital assets.

Files in the Project

Asset.py – makes the Asset class (CryptoToken, Data Spike, etc.)

Rig.py – makes the Rig class (a hacker’s computer system)

Hacker.py – makes the Hacker class (the player who controls the rig)

Main.py – runs the story and shows how everything works

Tests.py – has tests to check that the program works correctly

How to Run

To see the program in action, run this in your terminal:

python Main.py


To test the program:

python -m unittest Tests.py

What It Shows:

How classes work together

Using methods and attributes

Encryption and decryption

Rig upgrade and repair

Simple battle system

Trace level control
